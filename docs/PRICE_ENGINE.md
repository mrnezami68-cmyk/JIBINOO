# 📈 موتور قیمت جیبینو — راهکار چندمنبعه (Price Engine)

این سند معماری «راهکار به‌روزرسانی قیمت‌ها» را شرح می‌دهد؛ الهام‌گرفته از رویکرد پروژه
«دیدبان هوشمند بازار»: **استخراج هم‌زمان از چند API مستقل، نرمال‌سازی واحدها، محاسبه
قیمت‌های مشتق (دلار/ریال و فلزات) و کش آخرین قیمت واقعی.**

پیاده‌سازی: `src/lib/prices.ts` — وضعیت منابع به‌صورت زنده در بخش «نرخ‌های مرجع» صفحه
دارایی‌ها نمایش داده می‌شود.

---

## ۱. چرا قیمت‌ها «ثابت» می‌شدند؟ (مشکل قبلی)

موتور قبلی فقط ۲ منبع خارجی (`open.er-api.com` + `api.coingecko.com`) داشت و در صورت خطا
به **مقادیر ثابت هاردکد** برمی‌گشت — بدون کش آخرین قیمت واقعی. از داخل ایران معمولاً
دسترسی به این دو منبع ناپایدار/مسدود است ⇒ قیمت دلار و طلا همیشه روی اعداد ثابت می‌ماند.
مشکل دوم، «نرخ رسمی» er-api بود که فاصله بسیار زیادی با نرخ بازار دارد.

## ۲. معماری جدید

```
                    ┌────────────────────────────────────────────┐
                    │           fetchLivePrices() — موازی          │
                    └────────────────────────────────────────────┘
 منابع بازار ایران                     منابع جهانی                پشتیبان
┌───────────────────┐            ┌──────────────────────┐    ┌──────────┐
│ ۱) طلایار / TGJU   │            │ ۳) CoinGecko         │    │ ۶) er-api │
│ (JSON استاتیک،     │            │ رمزارز + PAXG        │    │ نرخ رسمی  │
│  GitHub Pages،     │            │ ۴) Gold-API          │    └──────────┘
│  CORS باز)         │            │ XAU / XAG / XPT      │
│ ۲) بیت‌پین tickers │            │ ۵) یاهو/COMEX (مس)   │
└───────────────────┘            └──────────────────────┘
        │                                  │
        └────────────► انتخابگر ◄──────────┘
              دستی ← مستقیم ← مشتق ← کش ← ثابت
```

همه فراخوانی‌ها **موازی و ایزوله**‌اند؛ خطا/timeout هر منبع ثبت و بقیه کار می‌کنند.
نتیجه هر منبع در آرایه `sources` (سلامت منبع) می‌آید و در UI با ✓/✕ نمایش داده می‌شود.

## ۳. منابع و پوشش

| منبع | Endpoint | پوشش | یادداشت |
|---|---|---|---|
| طلایار / TGJU | `javadisaloo1111.github.io/Currency-App/api/v1/market/prices.json` | دلار/یورو/درهم/لیر، طلای ۱۸ و ۲۴ گرم، مثقال (آب‌شده)، سکه امامی/بهار/نیم/ربع/گرمی | داده TGJU به‌صورت JSON استاتیک (به‌روزرسانی خودکار)؛ از GitHub Pages سرو می‌شود ⇒ مشکل CORS ندارد |
| بیت‌پین | `api.bitpin.org/api/v1/mkt/tickers/` | بازارهای تومانی: USDT/BTC/ETH/SOL/XRP/DOGE/ADA/TRX/BNB/LINK/AVAX + درصد تغییر ۲۴ ساعته | مبنای **نرخ مشتق دلار** (تتر) |
| CoinGecko | `api.coingecko.com/api/v3/simple/price` | قیمت دلاری ۱۲ رمزارز + PAXG (اونس طلا) | ممکن است rate-limit بدهد |
| Gold-API | `api.gold-api.com/price/{XAU,XAG,XPT}` | اونس طلا/نقره/پلاتین | پلاتین و نقره فقط از اینجاست |
| یاهو / COMEX | `query1.finance.yahoo.com/v8/finance/chart/HG=F` | مس آتی (دلار بر پوند) | نیازمند ضرب ۲٫۲۰۴۶۲ برای تبدیل به کیلوگرم |
| er-api | `open.er-api.com/v6/latest/USD` | نرخ **رسمی** دلار | فقط پشتیبان آخر — با نرخ بازار فاصله زیادی دارد |

## ۴. نرمال‌سازی واحدها (ریال ← تومان) — نکته حیاتی

فید TGJU/طلایار **واحدهای مخلوط** دارد (این موضوع با تطبیق داخلی «طلای ۱۸ ← اونس جهانی»
کشف و تأیید شد — CHANGELOG فاز ۸):

| نمادها | واحد واقعی فید | تبدیل به تومان |
|---|---|---|
| `GOLD_18K`, `GOLD_24K` | تومان | مستقیم |
| `USD EUR GBP AED TRY CNY CHF USDT BTC COIN_* GOLD_MESGHAL GOLD_OUNCE_TM` | **ریال** | ÷ ۱۰ |

بیت‌پین: جفت‌های `_IRT` عملاً به **تومان** (تأییدشده با تطبیق USDT/BTC با دروازه).
Gold-API/یاهو/کوین‌گکس: دلار.

## ۵. فرمول‌های قیمت مشتق

| قیمت | فرمول |
|---|---|
| **نرخ دلار بازار** | `USDT_IRT بیت‌پین` (تتر جایگزین دلار) — با اولویت پایین‌تر از USD طلایار |
| طلای ۱۸ عیار (گرم) | `(اونس ÷ ۳۱٫۱۰۳۵) × ۰٫۷۵ × نرخ دلار` |
| طلای ۲۴ عیار (گرم) | `طلای ۱۸ × (۲۴÷۱۸)` |
| **طلای آب‌شده (مثقال)** | مستقیم `GOLD_MESGHAL` ؛ پشتیبان: `طلای ۱۸ × ۴٫۶۰۸ × (۷۰۵÷۷۵۰)` [مثقال آب‌شده ≈ ۴٫۶۰۸ گرم طلای ۱۷ عیار] |
| نقره (گرم) | `(XAG ÷ ۳۱٫۱۰۳۵) × نرخ دلار` |
| پلاتین (گرم) | `(XPT ÷ ۳۱٫۱۰۳۵) × نرخ دلار` |
| مس (کیلوگرم) | `HG=F ($/lb) × ۲٫۲۰۴۶۲ × نرخ دلار` |
| رمزارز (تومان) | مستقیم بازار تومانی بیت‌پین ؛ پشتیبان: `قیمت دلاری CoinGecko × نرخ دلار` |
| سکه‌ها | مستقیم TGJU (حباب سکه ذاتی است؛ مشتق‌سازی از طلا دقیق نیست) |

## ۶. زنجیره انتخاب (هر ردیف قیمت)

**دستی (تنظیمات کاربر)** ← **منبع مستقیم بازار** ← **مشتق** ← **کش آخرین قیمت واقعی** ← **مقدار ثابت آفلاین**

- برچسب هر قیمت در UI دقیقاً منبع برنده را نشان می‌دهد (طلایار/TGJU، بیت‌پین، CoinGecko، Gold-API، COMEX، نرخ رسمی، مشتق، دستی، کش، آفلاین).
- **کش** (`localStorage` با کلید `jibino.prices.v1`): بعد از هر دریافت موفق ذخیره می‌شود؛ در اجرای بعدی (حتی آفلاین) همان آخرین قیمت واقعی نمایش داده می‌شود — دیگر «قیمت ثابت هاردکد» نمی‌بینید.
- مقادیر ثابت (`FALLBACK`) فقط برای اولین اجرای کاملاً آفلاین‌اند و همیشه برچسب «آفلاین» دارند.

## ۷. به‌روزرسانی خودکار

- هر **۵ دقیقه** + هنگام **بازگشت به تب** (visibilitychange) اگر قیمت بیش از ۶۰ ثانیه کهنه باشد.
- تایمر با `ref` به آخرین تنظیمات (نرخ دستی) دسترسی دارد (بگ closure قدیمی در Layout رفع شد).

## ۸. دارایی‌های پشتیبانی‌شده (بخش دارایی‌ها)

| طبقه | نمادها |
|---|---|
| طلا و سکه | طلای ۱۸، طلای ۲۴، **طلای آب‌شده**، **سکه امامی**، **سکه بهار آزادی**، **نیم‌سکه**، **ربع‌سکه**، **سکه گرمی**، طلای دست‌ساز |
| ارز | دلار، یورو، درهم، لیر، سایر |
| رمزارز | BTC, ETH, USDT, SOL, XRP, DOGE, ADA, TRX, BNB, TON, LINK, AVAX, سایر |
| **فلزات** (طبقه جدید) | **نقره (گرم)**، **پلاتین (گرم)**، **مس (کیلوگرم)**، فلز دیگر |
| سایر | ماشین، ملک، تجهیزات (ارزش‌گذاری با میانگین خرید) |

## ۹. محدودیت‌های شناخته‌شده

- CORS: بیت‌پین/یاهو/er-api ممکن است در برخی شبکه‌ها CORS ندهند؛ موتور تحمل خطا دارد و منابع دیگر جبران می‌کنند. طلایار (GitHub Pages)، Gold-API و CoinGecko معمولاً بازند.
- نرخ رسمی er-api ≠ نرخ بازار؛ فقط پشتیبان است.
- تغییر ۲۴ ساعته نقره/پلاتین/مس فعلاً از سمت منبع محاسبه نمی‌شود (۰ نمایش داده می‌شود).
- حباب سکه در قیمت TGJU لحاظ است؛ برای دارایی «سکه» از مشتق طلا استفاده نمی‌شود.

## ۱۰. نقشه راه

1. **سرور واسط (Vercel Function) `/api/prices`:** جمع‌آوری سمت سرور از TGJU/بیت‌پین بدون محدودیت CORS + کش سمت سرور + منابع بیشتر (مثلاً نوبیتکس/والکس).
2. **نرخ مشتق چندگانه:** میانگین وزنی از تتر/USDC/PAXG÷اونس برای نرخ دلار + اختلاف (premium) حباب تتر.
3. **تاریخچه قیمت:** ثبت snapshot روزانه برای نمودار واقعی ارزش دارایی (به‌جای sparkline تزئینی).
4. **override دستی هر نماد:** در تنظیمات، قیمت دستی برای هر دلخواه (مثل مس) — فعلاً فقط دلار و طلای ۱۸.
5. **هشدار قیمت:** نوتیفیکیشن هنگام عبور از آستانه (مثلاً سقف/کف هدف فروش).
